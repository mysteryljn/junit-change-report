These two XML documents are synthetic, authored for this project. They model
JUnit-compatible testsuites/testsuite/testcase output; they are not captured
vehicle data and are not claimed to have been generated by a test runner.
They intentionally cover a nested suite, a regression, a recovery, an error,
an added skipped case, a removed case, and a duration regression.

pytest-before.xml and pytest-after.xml are real pytest 9.2.0 outputs generated
from the included original pytest_cases.py on Python 3.13 / Windows.
The intentionally failing case changes between phases. Reproduce with:

    python -m pip install pytest==9.2.0
    python scripts/generate_pytest_fixtures.py

The generated XML retains pytest's durations, timestamp, traceback and host
metadata; these values are not treated as stable golden text. Regression tests
assert the actual status changes instead. pytest is not a runtime dependency.

JUnit XML has multiple producer dialects. The supported common subset is
documented in README.md. All sources and fixtures are MIT licensed.
